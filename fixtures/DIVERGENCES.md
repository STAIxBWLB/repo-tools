# Documentation check divergences

The [recordings](check-docs/copies/) compare exit status and freshness on identical Git fixtures. Each fixture starts with stamps for the union of the five copies' required documents. Each recording names the source commit and the flags that source actually accepts. At these commits, agent-research accepts only `--require-fresh`, and agent-console also accepts `--json`. Only agent-hub accepts `--committed`. The [minimal config from the README](../README.md#configuration) disables required documents, directory stamp requirements, and the README Status check. The per-copy configs in the recordings directory retain each copy's own requirements and reproduce its verdicts on all cases.
